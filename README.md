# 麻雀

4人打ちリーチ麻雀（CPU 3人対戦）のブラウザゲーム。東風戦、25,000点持ち。

`index.html` をブラウザで開くだけで遊べます（単一ファイル、サーバー不要）。

## 主なルール・機能

- ダブルロンあり（頭ハネなし）、三家和了は流局
- 流局時のテンパイ料あり（合計3,000点）
- 一発、ダブルリーチ、嶺上開花、槍槓、海底摸月、河底撈魚、流し満貫、四風連打あり
- 役満：四暗刻、大三元、字一色、緑一色、清老頭、九蓮宝燈、小四喜、大四喜、四槓子（国士無双十三面待ち・四暗刻単騎・純正九蓮宝燈・大四喜はダブル役満）
- 本場（積み棒）あり、赤5あり、ドラ・裏ドラあり
- 対局ログを MJAI 形式（JSON Lines）で書き出し可能（他家の手牌は「?」で伏せる）
- CPU はルールベース＋期待値計算（和了確率×見込み打点−放銃リスク）で打牌を決定

Muse のスペース「麻雀」から書き出したものです。スペース側を修正してもこのリポジトリには自動では反映されません。
